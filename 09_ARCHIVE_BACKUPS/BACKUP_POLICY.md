# Archive Backup Policy

## Repository is the working research archive

Use Git commits as the version history for Markdown notes. Commit meaningful changes with clear messages.

## Backup rhythm

- Export a ZIP snapshot after a substantial research milestone.
- Keep at least one local copy outside the working device.
- Keep original copyrighted books and films in lawful personal storage, not in this public research repository.
- Do not rely on GitHub as the only copy of any irreplaceable source files.

## File hygiene

- Use stable IDs for studies.
- Keep filenames descriptive and consistent.
- Avoid duplicate "final-final" files.
- Record source limitations in each study.
- Do not overwrite a source-derived study without preserving meaningful history.
