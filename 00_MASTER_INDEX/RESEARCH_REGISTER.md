## Entry protocol

For each new source:
- Assign a unique ID.
- Record title, creator, edition, publisher, year, language, format, and source provenance only when verified.
- Record what was actually inspected: whole source, selected chapters, selected scenes, or excerpts.
- Add page / chapter / timestamp references only when directly checked.
- Keep interpretations separate from source facts.
- Add a Karuppi application only when it solves a specific dramatic problem.
